# Trabajo-Final-de-NLP-Text-Mining
English below

Este proyecto aborda la clasificación multi-etiqueta de géneros de películas a partir de descripciones textuales.

Se han explorado diferentes enfoques:
- Modelos clásicos de Machine Learning (TF-IDF con Regresión Logística y SVM)
- Modelos de Deep Learning basados en Transformers (RoBERTa)

El trabajo incluye:
- Preprocesamiento y análisis exploratorio de los datos
- Vectorización del texto mediante n-gramas de palabras y caracteres
- Implementación de modelos multi-label (One-vs-Rest)
- Fine-tuning de un modelo preentrenado (RoBERTa)
- Optimización de umbrales de decisión y selección Top-K de etiquetas
- Evaluación comparativa usando accuracy, precision, recall, F1-score y Hamming loss

El modelo final logra un buen equilibrio entre rendimiento y eficiencia computacional.

This project focuses on multi-label classification of movie genres from textual descriptions. 
Several approaches were explored, including classical machine learning models (TF-IDF with Logistic Regression and SVM) and deep learning methods using Transformer models (RoBERTa).



The work includes:
- Data preprocessing and exploratory analysis
- Feature extraction using word and character n-grams
- Implementation of multi-label classification models (One-vs-Rest)
- Fine-tuning of a pre-trained Transformer (RoBERTa)
- Optimization of prediction thresholds and Top-K label selection
- Comparative evaluation based on accuracy, precision, recall, F1-score, and Hamming loss

The final system balances performance and computational efficiency.
